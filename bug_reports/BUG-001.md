# BUG-001 — Post Preview Fails to Load

## Summary
Post Preview displays a connection error instead of rendering the post.

## Severity
Medium

## Priority
High

## Area
Posts / Editor / Preview

## Environment
- Ghost: 5.130.6
- Deployment: Docker
- Host OS: Windows
- Browser: Chrome
- URL: http://localhost:3001

## Preconditions
User is logged into Ghost Admin and editing a post.

## Steps to Reproduce
1. Log in to Ghost Admin.
2. Open or create a post.
3. Enter post content.
4. Click **Preview**.
5. Observe the preview window.

## Expected Result
The post preview should load and display the content.

## Actual Result
The preview area displays:
`localhost refused to connect`
